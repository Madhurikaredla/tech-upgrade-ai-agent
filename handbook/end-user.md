# End User

This manual is for seekers — spiritual participants who register for programs through the Infinitheism platform. Use it to understand how to navigate the registration experience, what information you will be asked to provide, and what to expect after you submit.

## Overview

This section describes the end-to-end seeker journey: discovering a program, completing the registration form, and receiving confirmation.

## Prerequisites

This section lists what a seeker needs before starting registration — a valid account, required profile fields, and any program-specific eligibility conditions.

## Core procedures

This section holds the numbered workflows seekers perform most often: registering for a program, checking registration status, and updating profile details.

## Reference

This section provides a field-by-field reference for the registration form and any status codes or messages a seeker may encounter.

## Troubleshooting

This section covers common registration failures — form errors, duplicate submissions, payment issues — and the steps to resolve them.

## Changelog

This section records changes to the seeker-facing experience across platform releases.
