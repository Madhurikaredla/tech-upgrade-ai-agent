# Admin

This manual is for program administrators at Infinitheism who use the AI agent to configure, preview, and publish programs. Use it to understand how to run a program configuration conversation, what the agent needs from you, and how to handle edge cases before publishing.

## Overview

This section describes the admin workflow from opening the configuration chat to a live, published program — including the preview-and-confirm loop that prevents broken programs from reaching seekers.

## Prerequisites

This section lists what an admin needs before starting a configuration session: access credentials, an understanding of the program type (HDB, MSD, TAT, or custom), and any seeker-facing content to be embedded in the form.

## Core procedures

This section holds the numbered workflows admins perform most often: creating a new program via conversation, attaching a form, reviewing the preview, and publishing.

## Reference

This section provides a reference for all program fields the agent can configure, the program-type templates available, and the state machine transitions from draft to published.

## Troubleshooting

This section covers common configuration failures — agent misunderstandings, validation blocks, publish errors — and how to correct them before retrying.

## Changelog

This section records changes to the admin-facing configuration experience across platform releases.
